Apa yang sama dengan aplikasi asli?
  • Tampilan formulir, format masukan, judul, dua mode keluaran, jumlah slide dan pilihan n8n.
  • Antrean satu per satu, progres per tahap, checkpoint, status perlu tinjauan, dan fungsi lanjutkan.
  • Tautan transkrip, ringkasan Word, PowerPoint, Action Plan Excel, catatan kualitas, bukti fakta, dan paket ZIP.
Yang berbeda: situs publik ini memakai data dan dokumen contoh tersimpan. Unggahan bebas, transkripsi, analisis AI, konfigurasi model dan koneksi n8n sungguhan memerlukan aplikasi lokal. Tidak ada API key yang diminta atau ditanamkan di halaman ini.
